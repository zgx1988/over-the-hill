# 栖野 TRAILBOUND

原创 3D 网页越野探索游戏测试版。驾驶经典四驱车，沿松风山谷的林间小路、浅溪和山坡寻找五处地标，也可以和最多三位朋友结伴探索、牵引脱困。

画面氛围与探索节奏参考《over the hill》，车辆、地图和场景由代码原创生成，没有使用或提取原游戏资产。

## 本地启动

需要 Node.js 22+ 和支持 WebGL 2 的 Chrome / Edge。

```sh
npm ci
npm start
```

打开 http://127.0.0.1:8787 。Windows 也可以双击 `START.cmd`。

## 操作

WASD / 方向键驾驶，空格刹车，F 低速四驱，E 绞盘/牵引，L 车灯，C 镜头，M 地图，R 救援，P 摄影。拖动画面调整视角，滚轮调整距离。

打开两个标签页，分别点击「匹配同行者」可验证真实联机；也支持创建房间和邀请码加入。
