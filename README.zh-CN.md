# 栖野 TRAILBOUND · 松风山谷

可实际驾驶的原创 3D 网页越野探索测试版。先本地试玩；**本项目没有发布到 Cloudflare 或其他公网托管**。

## 本地试玩

本地地址：**http://127.0.0.1:8787**

双击 `START.cmd` 启动服务（首次会安装依赖），保持启动窗口打开，再访问上述地址。也可以在项目目录运行：

```powershell
npm install --cache .npm-cache
npm start
```

需要 Node.js 22 或更新版本，以及支持 WebGL 2 的近期 Chrome / Edge。验证环境使用 Node.js 24.13.0 和 Chrome。

## 玩法和操作

- `W / S`：油门 / 减速后倒车；`A / D`：转向；方向键也可使用。
- `空格`：刹车。停车、陡坡松油门时需要刹车。
- `F`：切换 4H / 4L。低速挡限制速度并增加可用牵引力，适合坡道、溪流、脱困。
- `E`：连接/收回绞盘。优先选择前方 23 米内同行车辆，否则连接 24 米内的树木。
- `L`：车灯；`H`：喇叭；`T`：晴日 / 暮色 / 薄雾。
- `C`：切换追随、开阔、近景镜头；拖动画面环绕，滚轮调整距离。
- `M`：山谷地图；`P`：摄影模式，可保存当前风景 PNG。
- `R`：救援至最近的安全位置；`Esc`：菜单 / 返回。
- 触屏设备提供转向、油门、倒车和刹车按钮；桌面浏览器是当前主要测试平台。

从营地沿车辙出发，寻找浅溪渡口、湖畔木屋、落日观景台和北岭电台。营地前方约十米的交错土丘可以观察悬架行程与车桥交叉轴。地图中浅色路线可走通所有地标。没有比赛计时。

## 真实多人联机

同一台电脑打开两个浏览器标签，分别点击「匹配同行者」，会进入同一个未满的公开房间；每个房间最多 4 人。也可以「邀请朋友 → 创建房间」，另一客户端用 4 位邀请码加入。公开匹配、私有房间、容量限制、掉线离开、车辆状态和共同探索进度均由服务器处理。

按 `E` 可连接前方同行者的车。前车低速前进，后车松刹车，牵引绳会在拉紧时传递位置约束并缓慢收绳。按 `E` 收回。单人可用树木锚点自救。

当前默认服务只监听本机。若要在同一 Wi-Fi 的其他设备试玩，可手动在 PowerShell 中运行：

```powershell
$env:HOST='0.0.0.0'
npm start
```

然后使用这台电脑的局域网 IP 和端口 8787。可能需要由电脑所有者处理 Windows 防火墙提示；项目不会自动修改防火墙。**这不是互联网远程联机地址**。跨互联网的联机需要测试确认后再部署。

## 本版实现

- 880 × 880 米的原创地形、连续浅溪、小湖、山路车辙、松林、岩石、营地、木屋、观景台和电台。
- 一辆优先打磨的原创经典四驱车 PIONEER 42：双片风挡、雨刷、仪表、座椅、轮胎胎块、螺栓轮毂、前格栅、备胎、油桶、行李、车架、传动轴、差速器、钢板弹簧和减振器。
- 基于实际地形采样的四轮高度、受阻尼的车身俯仰/侧倾/垂向响应、整体桥交叉轴。桥长保持固定，车架保持刚性，轮胎跟随桥的姿态。
- 前灯照明、后红灯、发动机合成音、扬尘/涉水粒子、地图、中文探索目标和摄影保存。
- 60Hz 固定步长车辆计算，客户端预测，服务器校正，15Hz 房间快照与远车插值。客户端发送控制输入，不能直接上传自己的坐标。

## 仿真与完成度的实际边界

这是有可验证地形响应的**近似越野模拟原型**。它还不是完整刚体物理仿真：未实现轮胎接触力/Pacejka、真实差速器与传动系统、多连杆动力学、翻滚事故、车辆之间的实体碰撞、可变形泥雪、车损或软体拖绳。钢板弹簧可视化随桥位移变化，车身没有用固定正弦动画假装地形反应。

车辆是代码生成的原创细节模型，没有下载商业车型资产；它仍是简化的实时三维模型，不是扫描或电影级写实模型。首版仅有这一辆四驱车；牧马人风格车型、老卡车以及视频中的多轴探险车尚未制作。当前是秋季山谷，没有雪地关卡。天气为可切换的光照/雾氛围，不是完整气象系统。

车辆牵引使用简化的位置约束和绞盘收绳；没有绳体质量或弹性求解。房间和进度仅在服务内存中存在，重启即清空。没有账号、存档、全球匹配队列、语音或聊天。

## 验证

```powershell
npm test
npm start
# 另开一个终端
npm run test:browser
npm run build
```

`npm test` 自动启动独立本地测试服务，验证完整地形驾驶、刹车/倒车/救援、车辆牵引、真实 WebSocket 同步、房间容量和隔离、共享探索、颜色同步、断开连接。浏览器验证需要本机 Chrome；截图和测量保存在 `artifacts/`。详见 `VALIDATION.md`。

## Cloudflare 适配（未发布）

`cloudflare/worker.mjs` 和 `wrangler.jsonc` 已提供 Workers 静态资产 + Durable Objects WebSocket 适配，复用同一房间与车辆计算模块。可先构建，再运行本地模拟器：

```powershell
npm run build
npm run dev:cloudflare
```

本地模拟地址为 http://127.0.0.1:8788。没有部署命令、托管 Site 注册、付费服务订阅或新凭据。只有用户确认测试结果后才进入部署阶段。

当前适配用一个 Durable Object 管理测试版匹配及多个房间；活跃驾驶期间持续计算，不使用休眠。正式版本应按区域/大厅和独立房间拆分对象，进一步处理连接恢复、费用、容量和长期状态；本地通过并不等于已完成线上负载验证。

## 代码位置

- `public/`：Three.js 场景、车辆、交互界面与客户端。
- `shared/world.mjs`：地图、地形、路面、障碍与地标。
- `shared/physics.mjs`：车辆及牵引近似模拟。
- `shared/rooms.mjs`：公开匹配、私房、权威房间状态。
- `server.mjs`：Node.js 本地静态资源和 WebSocket 服务。
- `cloudflare/`：未来部署目标的适配器。
- `tests/`：驾驶和真实联机验证；`scripts/build.mjs` 生成 `dist/`。
