# 栖野 TRAILBOUND 0.2 · 多地图与越野车足球

先本地测试：**http://127.0.0.1:8790**。线上部署方式与验证状态见 `DEPLOYMENT.md`。

## 启动

需要 Node.js 22+ 和支持 WebGL 2 的近期 Chrome / Edge。双击 `START.cmd`，保持启动窗口打开，再访问上述地址；也可在本目录执行：

```powershell
npm ci --cache .npm-cache
npm start
```

源码运行包包含精简运行依赖，解压后双击 `START.cmd` 无需再次下载依赖；开发和测试仍需运行 `npm ci` 安装完整开发依赖。当前项目已装好依赖。

## 四个目的地

| 地图 | 人数 | 玩法与任务 |
| --- | --- | --- |
| 松风山谷 | 1–4 | 原有森林浅溪探索，发现五处地标；保留树木绞盘与两车牵引 |
| 白岭补给线 | 1–4 | 雪地运输：到仓库停稳两秒装载、到救援屋停稳交接、把电池送到山顶信标 |
| 悬谷机关道 | 1–4 | 按序穿过受车重影响的跷跷板、两根并排窄木梁、自动运输的滑索平台；掉落回最近检查点 |
| 山野足球场 | 最多 5 对 5 | 两个球门、中场开球、五分钟比赛时钟、真人或 AI 混编、计分及赛后重开 |

进入游戏前选择地图。普通地图「独自出发」也使用本地权威服务器；「匹配同行者」只寻找同一地图的公开房间。在线数量来自服务器实际连接，不是模拟人数。也可创建私房，把四位邀请码发给朋友。

原有详细经典四驱车模型、车灯、轮胎接地、刚性车架、整体桥、钢板弹簧、减振器、俯仰与侧倾继续使用。AI 远车使用简化模型控制渲染开销。

### 双人乘员更新

驾驶位和副驾驶位都有原创成年人比例人偶，包含头部五官、帽子、户外服、手套、长裤、靴子及安全带。驾驶员双手握住方向盘，方向盘轮辐与手掌随车辆实际转向同步，肩膀、肘和前臂用双关节逆向计算保持握持。副驾驶保持坐姿，手部扶靠车内。

两人的上身与头部根据加减速、转弯和车身垂向运动产生受阻尼的俯仰、侧倾和回弹；驾驶员的扶握约束让动作比副驾驶更克制。联机车辆使用已有的转向和车辆状态驱动同样的动作；AI 和手机端简化车辆也有两名乘员，并用实例化零件减少渲染调用。

这是程序化关节模型与惯性动画，不是人体刚体或布料物理。刷新 `http://127.0.0.1:8790` 即可加载新人物。

## 机关玩法

- **跷跷板**：建议挂低速挡，保持中心方向。桥的角度由桥上车辆相对支点的位置和阻尼响应决定，不是预设循环动画。
- **双股木梁**：对齐左右轮，慢速直行。两根梁宽约 0.56m，间距与车辆轮距对应；中间和两侧是真正的空隙。跌落后自动返回检查点，也可按 R 救援。
- **滑索平台**：把车开到板上，平台自动刹停车辆，短暂准备后沿滑索运输到对岸。到站后驶离继续前往终点；平台无人时自动返回，供同伴继续使用。该运输平台会实际携带车辆位移。

任务导航同时提供屏幕方向箭头、距离、金色地面路线，以及右上角小地图上的目的地和同伴。雪地任务需要停稳交接，开过去不会直接完成。

## 足球玩法

选择山野足球场后：

- 「人机对战」直接建立 1 名真人加 9 个 AI 的比赛，平衡为两队各 5 辆车，倒计时后中场开球。
- 「真人匹配」进入公开足球房间；也可以创建私房邀请朋友。
- 真人不足时，任何真人都可用「+1 AI」或「补齐 5 对 5」补充人数。满员后按钮禁用。后加入的真人会替换自己队中的 AI，始终最多 5 人一队。
- 房主点击「开始比赛」，或用「重赛」重置比分、五分钟时钟、足球与车辆位置。房主离开后由仍在线的真人接任。
- 蓝方攻击橙色球门，橙方攻击蓝色球门。用车辆实际撞击足球射门；足球受速度、碰撞、滚动阻力和反弹影响。
- 比赛时钟为 05:00。初始/进球后的短暂中场开球倒计时不扣比赛时间；进球展示期间会继续扣时。时钟到零后冻结比赛并显示胜负或平局。
- 小地图发光三角是自己，金色发光圆是足球，蓝/橙小点是双方车辆。顶部显示服务端比分、时间和阶段。

AI 使用服务端驾驶控制，含进攻、支援和简单守门位置；不是假在线玩家。AI 的战术、避让和控球还比较基础。

## 桌面操作

W / S：油门 / 减速后倒车；A / D：转向；方向键也可使用。

空格：刹车；F：低速四驱；E：绞盘/牵引；L：灯；H：喇叭；C：三种镜头；拖动画面环绕；滚轮远近；M：地图；R：救援；P：摄影；Esc：菜单。足球模式关闭低速挡和绞盘。

## 手机触屏与横竖屏

手机有左侧方向键、右侧油门/倒车/刹车。支持多个手指同时转向和加速，手指滑出按钮时仍通过指针捕获跟踪，抬手、触摸取消、页面失焦或屏幕旋转会释放输入。

常用工具按钮可切换低速挡、绞盘、灯光、镜头和救援；顶部可打开菜单和地图。地图选择、房间创建/邀请码加入、添加 AI、开始比赛和重赛也能触摸操作。横屏和竖屏使用不同布局，游戏画面禁止浏览器滚动手势，菜单仍可上下滚动。

当前已在 Chrome 的 390×844 竖屏、844×390 横屏和 CDP 多点触控事件中实际测试，并非只有缩放截图。**尚未使用实体 Android / iPhone 做性能和兼容性验证**；推荐横屏。iOS Safari、低端机帧率和长时间发热仍需真机测试。

## 本地与同 Wi-Fi 试玩

同一电脑开两个浏览器标签页，分别选择同一地图并点击匹配，即可验证联机。足球场可实测两名真人再补齐八名 AI。

手机不能用自己的 `127.0.0.1` 访问电脑。在同一 Wi-Fi 下，先手动启动局域网监听：

```powershell
$env:HOST='0.0.0.0'
npm start
```

然后在手机输入这台电脑的局域网 IP，例如 `http://192.168.x.x:8790`。Windows 防火墙可能需要电脑所有者处理提示，项目不会自动修改防火墙。这里只是局域网测试入口，**不是互联网访问地址**。以后获得部署确认后，手机可通过正式 HTTPS 网站地址访问相同触屏界面。

## 断线恢复与状态

浏览器会话保存最近房间的恢复标记。断线或刷新后，在菜单点击「恢复上次房间」，60 秒内可恢复车辆、任务、房间以及正在进行的比分与时间。已被其他真人占满的队伍可能无法恢复；可重新匹配。主动离开房间会清除本次恢复标记。

房间与游戏状态目前只在服务进程内存中，服务重启或关闭会清空；不是长期账号存档。没有真人在线的恢复等待房间暂停模拟，超时自动清理。

## Cloudflare 适配

保留 Workers 静态资源 + Durable Objects 权威 WebSocket 适配。0.2 版多地图、任务、机关、球、AI、比分和计时均复用服务器相同模块，并已用本地模拟器测试。可运行：

```powershell
npm run build
npm run dev:cloudflare
```

本地模拟地址 http://127.0.0.1:8791 。这不创建公网网站，不需要登录，也不执行部署。当前原型仍用一个大厅对象管理房间；正式上线前应进一步拆分房间对象并处理容量、费用和长期状态。

## 现实边界

车辆仍属于近似越野模拟，不是完整刚体/真实轮胎/传动仿真；没有翻滚损坏、可变形泥雪或绳体质量/弹性求解。足球碰撞使用简化形状和速度冲量，机关用动态高度面与携带约束；它们实际影响车辆，但不是完整机械约束物理引擎。

保留一辆原创经典四驱车，未增加正式授权品牌车型或老卡车。雪地与机关美术是可玩的程序生成版本。未做跨地区互联网、高并发、实体手机或所有浏览器验证。

本仓库是最新代码的同步副本；本地开发目录及旧版本仍保留。部署记录见 `DEPLOYMENT.md`。
